Exploratory Data Analysis

Key Findings from EDA

📊
Class Imbalance

nv dominates at 67% of all samples. Melanoma (the most dangerous class) represents only 11%. Minority classes df and vasc together account for just 2.5%.

58× imbalance ratio
🎨
Pixel Intensity

All three channels show high mean intensity (R≈0.76, G≈0.55, B≈0.57) — skin images are bright. Narrow std values indicate low inter-image color variance: custom normalization is critical.

HAM-specific norm used
🔍
Augmentation Impact

Before/after grid revealed that random flips, rotations, and color jitter preserve clinical features while increasing effective diversity. Aggressive crop was avoided to retain lesion boundaries.

+3% val accuracy
⚡ Key Insight: Why Standard Oversampling Wasn't Enough

Naive ROS caused the model to memorise minority class textures. √-weighted WeightedRandomSampler softens the distribution without collapsing majority-class generalisation.

Architecture Modification
# Replace classifier head for 7 classes m = efficientnet_v2_s(weights=IMAGENET1K_V1) in_features = m.classifier[1].in_features m.classifier = nn.Sequential( nn.Dropout(p=0.3), nn.Linear(in_features, 7) )
Two-Phase Fine-tuning
  • Phase 1: Freeze backbone, train head only (5 epochs)
  • Phase 2: Unfreeze all, backbone lr = 3e-5
  • Head lr = 3e-4 with OneCycleLR scheduler
  • Prevents catastrophic forgetting of ImageNet features

√-Weighted Sampler
w_cls = 1 / sqrt(class_counts) sample_w = w_cls[labels] sampler = WeightedRandomSampler( weights=sample_w, num_samples=len(train_ds) )

√ softens imbalance vs. full inverse — preserves nv generalisation

Loss Function
criterion = nn.CrossEntropyLoss( weight=class_weights, label_smoothing=0.1 )

Focal loss abandoned — unstable with heavily imbalanced alpha vectors

Checkpoint Strategy
  • Save best model by melanoma recall
  • Not by val accuracy or val loss
  • Threshold tuned post-training
  • MEL_THRESHOLD = 0.35
Threshold Tuning

Melanoma Decision Threshold = 0.35

Prediction Override Logic
probs = softmax(model(x)) mel_prob = probs[MEL_IDX] # idx 4 if mel_prob >= MEL_THRESHOLD: pred = MEL_IDX # override else: pred = probs.argmax() # default
Scan Range: 0.15 → 0.35

Threshold scan tested every 0.05 step. 0.35 chosen as the sweet-spot that keeps melanoma recall above 80% while limiting over-flagging of benign lesions as high-risk.

Medical Ethics & Responsible AI

Responsible AI in Healthcare

"This tool is for screening assistance only and does not constitute a medical diagnosis. Please consult a licensed dermatologist for any skin concerns."

Why This Disclaimer Matters
  • AI cannot examine lesion texture/depth clinically
  • Image quality, lighting, and angle affect results
  • Threshold optimised for recall — may false-positive
  • Legal liability lies with the clinician, not the tool
Design Choices with Ethical Intent
ChoiceEthical Rationale
Recall-first objectiveMissing cancer = harm
mel_prob in responseTransparency for clinicians
3-tier risk outputActionable, not alarming
Disclaimer in every callPrevents over-reliance
⚠️ Known Limitations
  • Dataset is predominantly light skin tones
  • No clinical metadata used (age, location)
  • No uncertainty quantification (Bayesian)
